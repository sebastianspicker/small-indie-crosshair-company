# v0.3.0 architecture and quality boundaries

The normal application, CLI verification, build and deployed website still require no
npm dependencies. Shared pure library modules remain usable without DOM or a server.

## Domain modules

`renderer.js` defines and validates 27 canonical forward scenarios. `inverse.js` minimizes
a specified integer-domain geometry objective. `visual.js` freezes a target, caches shape
losses and performs bounded local refinement. `selection.js` evaluates and refines under
an explicit cross-scenario decision rule. `report.js` builds a provenance-bearing report;
`inference.js` only orchestrates those stages. `models.js` preserves the previous import
surface through re-exports; no duplicate solver implementation is introduced there.

`pixel-shape.js` is independent of hypothesis likelihoods. It losslessly compiles rectangle
unions or measured binary masks. Rendering them identically under a hypothesis is a
mathematical comparison, not evidence about that hypothesis's authenticity.

`observations.js` validates/canonicalizes/deduplicates capture data; `evidence.js` updates
conditional robust weights and evaluates disjoint holdouts. `experiments.js` caches
noiseless prediction partitions for experiment suggestions. `components.js` independently
measures native-image component bounds without imposing historical near/far equality.

`native-settings.js` is the single native-value validation, color resolution and CFG
formatting boundary. It is shared by the automatic exporter and retained manual lab.

## Application modules

`app/quant.js` loads source data and creates a controller. `quant/view.js` defines semantic
controls; `presentation.js` updates values, canvases, derivations and progressively
rendered scenario tables. `sources.js` and `feedback.js` handle their respective input
boundaries; `controller.js` owns request generations, debouncing and cleanup.

`image-input.js` checks file/header/decoded-image limits. `image/view.js` describes the
controls; `image/dialog.js` owns selection state, analysis snapshots and lifetime. A new
selection invalidates an accepted fit immediately. Dialog lifetime, not completion of
initial analysis, determines whether another image can be opened.

`worker-client.js` is a bounded serial transport, not a fallback solver. Clone failures,
protocol failures, deadlines and disposal settle all affected requests. The main UI does
not silently switch production inference to the main thread when worker startup fails.

## Quality evidence

The optional `npm run audit:complexity` uses Node's bundled Acorn parser with
`--expose-internals`; it adds no shipped dependency. Its definition counts per-function
AST decisions and excludes nested functions from parent counts. It is a reproducible
cyclomatic-complexity proxy, not a formal control-flow graph proof. Comparisons report
maximum, percentile, counts above a threshold and individual hotspots, including added
functions rather than hiding growth in the total decision count.

The calculation certificate is checked against an exhaustive oracle; analytical overlap
is checked against the old dense raster. These are independent implementation checks
against the declared model, not independent native-client verification. Benchmarks use
the same fixed case schedule and warm-up protocol before and after this change. Browser
interaction tests record their in-memory transport limitation explicitly.

## Design intent and visual QA

Keep the existing dark visual system but remove the oversized hero/stat strip and
nested decorative surfaces. Prioritize a literal value table, recognizable cvar names,
source resolution and computed target. Three synchronized previews follow rather than
precede the numbers. Detailed assumptions, traces and evidence remain reachable without
requiring every user to navigate them. The worst-case decision rule lives in advanced
matching controls. No percentage is labeled native confidence without native evidence.

The visual-review checklist covers value-table hierarchy, cvar casing, restrained palette,
small-control typography, column alignment, preview synchronization, progressive expert
panels, keyboard/focus behavior and 390/768/1440-width layouts. QA images and temporary
browser scripts are kept outside the repository; release verification records results.
